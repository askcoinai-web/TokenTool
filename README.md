## 功能板块

## 经典代币
[标准代币](https://tokentool.org/#/co/st/?t=0)：基于标准 ERC-20 协议的代币

[MEME代币](https://tokentool.org/#/co/st/?t=1)：模因币，一种幽默讽刺、单价便宜、社区传播的代币  

[公平发射](https://tokentool.org/#/co/fa)：允许任何人一键部署无主代币并参与铸造  

[一般代币](https://tokentool.org/#/co/nm)：转账手续费、权限假放弃的ERC20代币  

[营销代币](https://tokentool.org/#/co/mk/?t=0)：交易滑点 + 黑白名单机制 + 邀请奖励 + 定时启动开盘 

[持币分红](https://tokentool.org/#/co/dd/?t=0)：交易滑点 + 持有该代币则可获得代币分红（如DOGE、SHIB） + 黑白名单机制 + 邀请奖励 + 定时开盘 + 地址裂变 + 交易冷却  

[持币复利](https://tokentool.org/#/co/cp/?t=0)：交易滑点 + 持有该代币则钱包每天不断复利 + 黑白名单机制 + 邀请奖励 + 定时开盘 + 地址裂变 + 交易冷却  

[加池分红](https://tokentool.org/#/co/ld/?t=0)：交易滑点 + 添加流动性可获得代币分红 + 黑白名单机制 + 邀请奖励 + 定时开盘 + 地址裂变 + 交易冷却  

[铭文代币](https://tokentool.org/#/co/ins)：公平发射代币

## dApp项目

## 预售
[简单预售](https://tokentool.org/#/la/st)：单个代币（如 USDT、USDC、ETH） 购买即将发行的代币 + 邀请奖励 

[综合预售](https://tokentool.org/#/la/ad)：用户可使用多种主流代币（如 USDT、USDC、ETH） 购买即将发行的代币，并且有预售团队统计、多期预售、多级邀请奖励功能 

[多期预售](https://tokentool.org/#/la/ad)：可以进行一期、二期、三期...预售

[公平发射](https://tokentool.org/#/la/fa)：FERC20公平发射平台，允许任何人一键部署无主代币并参与铸造，独创的众筹模式快速构建流动性池，预置Free Mint、白名单、线性释放模块，同时提供独立私人铸造dApp，满足个性化发射需求 

[无dApp版](https://tokentool.org/)：无需dApp即可实现预售功能

## 挖矿
[简单挖矿](https://tokentool.org/#/mi/st)：把代币质押到矿池里，可实时获取挖矿奖励，质押的代币随时赎回 

[质押挖矿](https://tokentool.org/#/mi/ch)：通过算力计算挖矿奖励，代币锁仓即可获得质押算力，同时邀请也可获得推广算力奖励 

[减产挖矿](https://tokentool.org/#/mi/pr)：通过算力计算挖矿奖励，代币可以选择不同锁仓周期获得不同的质押算力，邀请也可获得推广算力奖励，并且挖矿会每隔一段时间进行减产 

[综合挖矿](https://tokentool.org/#/mi/pl)：多周期锁仓、减半机制、自动排线邀请，统计用户的质押、团队算力、锁仓、奖励等挖矿信息

## 理财
[质押赚币](https://tokentool.org/#/fi/ea)：用户质押代币（如 USDT ）理财，根据质押周期获取相应的年化率回报 

[烤牛肉](https://tokentool.org/#/fi/bf)：通过投入BNB（烤牛肉），获得BNB收益（吃牛肉），每日高达10%的奖励回报 

[烤豆子](https://tokentool.org/#/fi/bn)：一个锁定USDT静态收益 + 直推额外收益的奖励池，每日回报高达 6.5% 

## 铭文/符文

[符文预售](https://tokentool.org/#/ru/sa)：使用ETH/BNB等币种购买符文，符文可直接兑换成自己发行的代币

## Feature Overview

## Classic Tokens
[Standard Token](https://tokentool.org/#/co/st/?t=0)：ERC-20 token built on the standard protocol

[MEME Token](https://tokentool.org/#/co/st/?t=1)：Meme coin—humorous, low unit price, spread by the community

[Fair Launch](https://tokentool.org/#/co/fa)：Anyone can deploy ownerless tokens and mint in one click

[General Token](https://tokentool.org/#/co/nm)：Transfer tax; ERC-20 with “renounced” permissions that are not genuine

[Marketing Token](https://tokentool.org/#/co/mk/?t=0)：Trade slippage + allow/deny list + referral rewards + scheduled open

[Holder Dividend](https://tokentool.org/#/co/dd/?t=0)：Slippage + hold for token rewards (e.g. DOGE, SHIB) + allow/deny list + referrals + scheduled TGE + referral tiers + trade cooldown

[Holder Compound](https://tokentool.org/#/co/cp/?t=0)：Slippage + daily compounding in wallet for holders + allow/deny list + referrals + scheduled TGE + referral tiers + trade cooldown

[LP Dividend](https://tokentool.org/#/co/ld/?t=0)：Slippage + token rewards for LPs + allow/deny list + referrals + scheduled TGE + referral tiers + trade cooldown

[Inscription Token](https://tokentool.org/#/co/ins)：Fair-launch inscription token

## Presale-Ready Tokens
[Fair Launch (no dApp)](https://tokentool.org/#/co/50/?t=1)：Fair mint via transfers; no minting dApp required

[Standard Token (with presale)](https://tokentool.org/#/co/50/?t=0)：Presale over transfers for a standard token; no presale dApp required

[Holder Dividend (with presale)](https://tokentool.org/#/co/dd/?t=1)：Holder-dividend presale over transfers; no presale dApp required

[LP Dividend (with presale)](https://tokentool.org/#/co/ld/?t=1)：LP-dividend presale over transfers; no presale dApp required

[Holder Compound (with presale)](https://tokentool.org/#/co/cp/?t=1)：Holder-compound presale over transfers; no presale dApp required

[Marketing Token (with presale)](https://tokentool.org/#/co/mk/?t=1)：Marketing-token presale over transfers; no presale dApp required

## Swap-Style Tokens
[ERC314 Token](https://tokentool.org/#/co/314)：No AMM required—auto buy/sell via transfers

[X314 Token](https://tokentool.org/#/co/x314)：No AMM required—auto buy/sell via transfers + slippage + daily burn / deflation + trade cooldown (anti-MEV)

## Presale + Swap Tokens
[ERC314 Token (with presale)](https://tokentool.org/#/co/s314)：ERC314 with presale

[X314 Token (with presale)](https://tokentool.org/#/co/x314)：X314 with presale

## Lock-Up
[Linear — by period](https://tokentool.org/#/lo/id/?t=2)：Lock tokens (or LP) on-chain; release each period

[Linear — over time](https://tokentool.org/#/lo/id/?t=1)：Lock tokens (or LP) on-chain; vest linearly on a timeline

[Fixed unlock](https://tokentool.org/#/lo/id/?t=0)：Lock tokens (or LP) on-chain; full unlock at expiry

## dApp Projects

## Presale
[Simple presale](https://tokentool.org/#/la/st)：Buy upcoming tokens with one asset (e.g. USDT, USDC, ETH) + referral rewards

[Advanced presale](https://tokentool.org/#/la/ad)：Buy upcoming tokens with major assets (e.g. USDT, USDC, ETH); team stats, multi-round presale, multi-tier referrals

[Multi-round presale](https://tokentool.org/#/la/ad)：Supports round 1, 2, 3… presales

[Fair Launch](https://tokentool.org/#/la/fa)：FERC20 fair-launch: one-click ownerless deploy and mint; crowdfund-style liquidity bootstrapping; Free Mint, whitelist, linear release; optional private mint dApp for custom launches

[No-dApp mode](https://tokentool.org/)：Presale without running a dApp

## Mining
[Simple mining](https://tokentool.org/#/mi/st)：Stake in the pool for live rewards; withdraw stake anytime

[Staking mining](https://tokentool.org/#/mi/ch)：Hashrate-based rewards; lock tokens for stake hashrate; invites earn promotion hashrate

[Halving mining](https://tokentool.org/#/mi/pr)：Hashrate-based rewards; pick lock-up length for stake hashrate; invites earn promotion hashrate; periodic emission cuts

[Comprehensive mining](https://tokentool.org/#/mi/pl)：Multi-period lock-up, halving, upline invite; stats on stake, team hashrate, lock-up, and payouts

## Finance
[Stake to earn](https://tokentool.org/#/fi/ea)：Stake (e.g. USDT) for yield by lock-up term

[Roast beef](https://tokentool.org/#/fi/bf)：Stake BNB (“roast beef”) to earn BNB (“eat beef”)—up to ~10% daily

[Baked beans](https://tokentool.org/#/fi/bn)：USDT static pool + direct-referral bonus—up to 6.5% daily

## Inscriptions / Runes

[Inscription launch](https://tokentool.org/#/ins/pr)：Mint real inscriptions on-chain with ETH/BNB, etc.; referral rebates

[Rune presale](https://tokentool.org/#/ru/sa)：Buy runes with ETH/BNB, etc.; redeem for your own token

## DEX

[Batch create wallets](https://tokentool.org/#/wa/cr)：Create n wallets in one click (private key + mnemonic)

[Batch wallet lookup](https://tokentool.org/#/wa/ch)：Token balances and details per wallet

## Inscriptions
